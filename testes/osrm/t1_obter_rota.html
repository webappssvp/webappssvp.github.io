O que é o serviço OSRM?

Open Source Routing Machine • Malha Viária Aberta

O OSRM (Open Source Routing Machine) é um serviço de cálculo de rotas de altíssima velocidade construído sobre a base colaborativa mundial do OpenStreetMap (OSM). Permite alternar entre perfis de mobilidade como carro (`driving`), a pé (`walking`) ou bicicleta (`cycling`), fornecendo a malha viária completa (conversões, distâncias e tempos estimados) em formato aberto JSON / GeoJSON com custo zero.

💰 Custo Zero (R$ 0,00) Não requer cartão de crédito nem chaves privadas de API do Google Cloud.
🚶 Suporte A Pé e de Carro Calcula tanto visitas motorizadas quanto visitas a pé no mesmo bairro.
🔄 Formato Padrão GeoJSON Compatível nativamente com o mapa Leaflet e pronto para cálculo de rotas vicentinas.
