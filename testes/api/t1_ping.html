📊 Instruções do Teste de Conexão (Ping) +
❓ O que este teste valida? −
Este teste avalia o canal básico de comunicação entre a interface web do celular e a API do WebApp SSVP no Google Apps Script:
  • Conectividade HTTP: Se o Google Apps Script responde sem erros de CORS.
  • Latência Real (Ida e Volta): Quanto tempo o celular do vicentino aguarda para receber um retorno da nuvem.
  • Tempo do Servidor: Quanto tempo o script gastou processando no Google.
📋 Como executar o teste +
  1. Copie o código de testes/api/privado/t1_ping.gs e cole em um novo projeto no script.google.com.
  2. Implante como App da Web configurando "Quem pode acessar: Qualquer pessoa".
  3. Cole a URL gerada no campo abaixo e clique em "Salvar URL".
  4. Toque no botão "⚡ Disparar Ping" para realizar a medição de performance.
⚙️ Configuração da URL da API WebApp URL Não Configurada
🚀 Disparo de Health Check

Envia uma requisição POST /exec?action=ping para a API do WebApp SSVP e mede os tempos de resposta.
